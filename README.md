# Proyecto MLOps
📌 Descripción: Modelo de regresión con MLflow y CI/CD.

🎯 Problema: Se requiere desarrollar un modelo para estimar los precios de venta de viviendas de acuerdo a sus características.

📊 Data: La base de datos cuenta con 81 variables y 1460 observaciones.
